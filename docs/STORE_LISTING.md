## 详细描述 (Detailed Description) — 建议 500-2000 字符

```
═══════════════════════════════════════════
  WeCal Sync — 你的 Apple iCloud 日历浏览器伴侣
═══════════════════════════════════════════

【核心功能】

📅 今日日程一览
在 Chrome 侧边栏直接查看 iCloud 日历的今日和明日行程。事件卡片清晰展示时间、标题、地点，已过期日程自动变灰。每分钟自动同步，实时更新。

🔔 强力弹窗提醒
日程前 30 分钟 / 15 分钟 / 5 分钟 / 0 分钟自动弹出苹果风格精美提醒窗口，带动态铃铛动画和倒计时。180 秒自动关闭。

🔊 响铃告警
日程临近时自动播放强力警报音，即使浏览器在后台也不错过任何重要会议。

🧠 智能创建日程（三种方式）
1️⃣ 粘贴一句话："明天下午3点在星巴克开会" → AI 自动解析为日程（需 Deepseek API）
2️⃣ 手动表单：填写名称、时间、地点
3️⃣ 右键菜单：选中网页文字 → 右键 → "添加日程到 WeCal" → 一步创建

☁️ 连接 iCloud 日历
支持中国区 (iCloud.com.cn) 和国际区 (iCloud.com)。使用 Apple 官方 App 专用密码安全连接，CalDAV 协议直接读写你的日历。

【适用场景】
• 办公时经常在浏览器前工作，需要随时看日程
• 希望日程提醒弹窗+闹铃双重保障，避免错过会议
• 习惯在网页上选中文字快速创建日程
• 不想为了看日历而打开手机或 macOS 应用

【隐私保证】
• 所有数据仅存本地（chrome.storage.local）
• 没有追踪、没有广告、不上传任何个人信息
• 与 iCloud 的通信全程 HTTPS 加密
• 卸载后 iCloud 数据不受影响
```
