## 1. 产品简介

**WeCal Sync** 是一款 Chrome 浏览器扩展程序，让您无需打开手机或 macOS 即可在浏览器中：

- 实时查看 **Apple iCloud 日历** 的今日和明日日程
- 通过 **自然语言智能识别** 快速创建日程
- 在日程临近时弹出 **强力提醒窗口并播放警报音**

适用于：
- 日常办公需要随时查看日历的职场人士
- iCloud 用户希望在 Chrome 中获得原生般的日历体验
- 需要强力提醒避免错过会议的用户

### 技术特性

| 特性 | 说明 |
|------|------|
| 架构 | Chrome Extension Manifest V3 |
| 协议 | CalDAV（iCloud 日历同步协议） |
| 智能识别 | Deepseek AI API |
| 数据存储 | 仅存储在本地 `chrome.storage.local` |
| 音频播放 | Chrome Offscreen API |
| 权限 | 最少必要权限原则 |

## 2. 安装与卸载

### 2.1 从 Chrome 应用商店安装

1. 打开 Google Chrome 浏览器
2. 访问 Chrome 应用商店中 WeCal Sync 的页面
3. 点击 **「添加至 Chrome」**
4. 弹出权限确认窗口，点击 **「添加扩展程序」**
5. 安装完成后，浏览器工具栏右侧会出现 WeCal Sync 图标

### 2.2 打开侧边栏

**方法一：** 点击浏览器工具栏中的 WeCal Sync 图标
**方法二：** 快捷键 `Ctrl + 鼠标点击` 图标（部分版本支持）

### 2.3 卸载

1. 在 Chrome 地址栏输入 `chrome://extensions/`
2. 在列表中找到 **WeCal Sync**
3. 点击 **「移除」** 按钮
4. 确认卸载

> **提示**：卸载不会影响 iCloud 日历中的任何数据。卸载后仅清除扩展的本地配置信息。

## 3. 配置 iCloud 日历

首次使用需要配置 iCloud 账号连接。这是使用 WeCal Sync 的**唯一前提条件**。

### 3.1 获取 App 专用密码

> ⚠️ **重要**：WeCal Sync 要求使用 Apple 官方的 **App 专用密码**，**不是**您的 iCloud 登录密码。

1. 访问：**[appleid.apple.com/account/manage](https://appleid.apple.com/account/manage)**
2. 使用您的 Apple ID 登录
3. 进入 **「登录和安全」→「App 专用密码」**
4. 点击 **「+」** 生成新密码
5. 将生成的密码（格式为 `xxxx-xxxx-xxxx-xxxx`）复制并保存好

### 3.2 配置步骤

**步骤 1：进入设置**

打开 WeCal Sync 侧边栏，点击底部导航栏的 **「设置」**。

**步骤 2：选择云服务入口**

| 选项 | 适用用户 |
|------|----------|
| 中国 (iCloud.com.cn) | Apple ID 为中国区账号的用户 |
| 全球 (iCloud.com) | 海外 Apple ID 用户 |

**步骤 3：输入账号信息**

- **Apple ID**：您的 iCloud 邮箱地址
- **App 专用密码**：上一步生成的密码

**步骤 4：验证并选择日历**

点击 **「验证账号」** 按钮。验证通过后，系统会自动拉取您的日历列表。

在「日历名称」下拉框中选择要同步的日历。

**步骤 5：保存**

点击 **「保存配置」**，系统将自动跳转至今日日程视图。

> **提示**：您可以在「设置」页面随时修改配置或切换日历。

## 5. 创建日程（三种方式）

### 5.1 方式一：自然语言智能识别（推荐）

最快的方式——粘贴一句话，AI 自动识别所有信息。

**操作步骤：**

1. 在今日视图点击 **「+ 新建日程」**
2. 在粘贴文本框中输入自然语言描述，例如：

   ```
   明天下午3点在星巴克和客户开会
   ```

   或：

   ```
   下周一上午9点到11点产品评审会 @腾讯会议
   ```

3. 在 **Deepseek API Key** 输入框中填入您的 Deepseek API Key
4. 点击 **「智能识别」** 按钮
5. 系统自动解析出：日程名称、开始时间、结束时间、地点
6. 确认表单信息无误
7. 点击 **「添加」** 提交至 iCloud

**智能识别支持的时间表达：**

| 输入示例 | 识别结果 |
|----------|----------|
| "明天下午3点" | 自动计算明天的日期 + 15:00 |
| "下周一9:00-11:00" | 自动计算下周一的日期和时间段 |
| "每周五上午10点" | 本周五的 10:00（单次事件） |
| "现在半小时后" | 当前时间 + 30 分钟 |
| "大后天" | 三天后的日期 |

> **提示**：智能识别仅用于解析文本，不会发送或存储您的日程数据到第三方服务器。

### 5.2 方式二：手动创建表单

**操作步骤：**

1. 在当前视图点击 **「+ 新建日程」**
2. 填写表单各字段：

   | 字段 | 说明 | 必填 |
   |------|------|------|
   | 日程名称 | 事件的标题 | 是 |
   | 开始时间 | 日期 + 时间 | 是 |
   | 结束时间 | 日期 + 时间 | 是 |
   | 地点 | 举办地点（可选） | 否 |

3. 点击 **「添加」** 提交至 iCloud

### 5.3 方式三：右键菜单快速创建

在浏览任意网页时，快速选中文字创建日程。

**操作步骤：**

1. 在网页中选中一段包含日程信息的文字
2. 右键点击，在菜单中选择 **「添加日程到 WeCal」**
3. 侧边栏自动打开并跳转到创建页面
4. 选中的文字已自动粘贴到输入框中
5. 使用智能识别或手动调整后点击 **「添加」**

**适用场景：**

- 在邮件中看到会议通知 → 选中文字 → 右键添加
- 在微信网页版聊天记录中找到时间安排 → 选中 → 右键添加
- 在工作文档或公告中看到日程 → 选中 → 右键添加

### 5.4 创建成功确认

创建成功后，会跳转到确认页面，展示：


## 6. 日程提醒与告警

### 6.1 提醒时间点

WeCal Sync 会在以下时间点自动弹出提醒：

| 触发点 | 说明 |
|--------|------|
| 日程前 30 分钟 | 首次提醒 |
| 日程前 15 分钟 | 再次提醒 |
| 日程前 5 分钟 | 临近提醒 |
| 日程开始时刻 | 立即提醒 |

### 6.2 提醒窗口

提醒窗口是一个独立的弹窗页面，包含：

- **🔔 动态铃铛图标** — 持续摇晃动画
- **红色警示条** — 顶部醒目红色条
- **事件标题** — 红色大字显示
- **开始时间** — 格式为 `HH:mm`
- **预估时长** — 显示分钟数
- **地点** — 如果设置了的话
- **倒计时** — "X 分钟后开始"
- **自动关闭** — 180 秒后自动关闭
- **「我知道了」按钮** — 手动关闭

### 6.3 警报音

- 每次弹窗同时播放强力警报音
- 音频通过 Chrome Offscreen API 播放（无需用户交互即可发声）
- 音量为系统默认播放音量

### 6.4 关闭提醒

- 点击 **「我知道了」** 按钮
- 等待 180 秒自动关闭
- 关闭后不影响后续时间点的再次提醒

## 7. 常见问题

### Q1：为什么连接不上 iCloud？

常见原因：
- App 专用密码格式错误（应为 `xxxx-xxxx-xxxx-xxxx`，不含空格）
- Apple ID 和所选云服务入口不匹配（中国区选 iCloud.com.cn，海外选 iCloud.com）
- 网络环境受限（检查能否访问 iCloud 网站）
- App 专用密码已过期（需要去 appleid.apple.com 重新生成）

### Q2：App 专用密码和普通密码有什么区别？

Apple 的 App 专用密码是一种一次性生成的随机密码，专门用于"非 Apple 设备或软件"登录 iCloud。它比您的普通密码更安全（可以随时撤销），也是 WeCal Sync 连接 iCloud 的唯一方式。

**生成路径**：[appleid.apple.com](https://appleid.apple.com/account/manage) → 登录和安全 → App 专用密码

### Q3：智能识别需要 Deepseek API Key？从哪里获取？

是的，自然语言解析功能依赖 Deepseek API。您需要：

1. 访问 **[platform.deepseek.com](https://platform.deepseek.com)** 注册账号
2. 在 API Keys 页面创建新的 API Key
3. 复制 Key（格式为 `sk-...`）粘贴到 WeCal Sync 的输入框

**费用**：Deepseek API 价格低廉，单次日程识别仅消耗极少量 token（约 0.001 元人民币/次）。

### Q4：日程提醒没有声音？

可能原因：
- 浏览器标签页被静音（检查标签页右键菜单的"将网站静音"选项）
- Chrome 音频策略限制（尝试在 Chrome 地址栏输入 `chrome://flags/#autoplay-policy` 确认）

### Q5：右键菜单没有"添加日程到 WeCal"？

- 请确认已选中网页中的文字（文字高亮）
- 如果没有选中文字，Chrome 不会显示此菜单项
- 如果是刚安装的扩展，可能需要刷新页面

### Q6：卸载后我的 iCloud 日历数据会丢失吗？

**不会。** WeCal Sync 只是一个"读取器/写入器"，它会读取和写入您 iCloud 日历中的数据。卸载扩展只删除保存在本地的配置信息（Apple ID、App 专用密码、Deepseek Key），iCloud 服务器上的日程数据不受任何影响。

### Q7：支持多日历同步吗？

目前一个配置仅同步一个日历。您可以在设置中随时切换要同步的日历。

### Q8：可以离线使用吗？

WeCal Sync 需要联网才能与 iCloud 通信。离线状态下无法查看或同步日程。

## 8. 隐私与安全

### 数据存储位置

| 数据类型 | 存储位置 | 说明 |
|----------|----------|------|
| Apple ID | 本地 `chrome.storage.local` | 仅用于 CalDAV 认证 |
| App 专用密码 | 本地 `chrome.storage.local` | 本地加密存储 |
| Deepseek API Key | 本地 `chrome.storage.local` | 仅用于智能识别调用 |
| 日历数据 | iCloud 服务器 + 本地缓存 | 从 iCloud 拉取的日程缓存 |
| 使用数据 | 无 | 不收集统计数据 |

### 网络通信

- 所有与 iCloud 的通信均使用 **HTTPS 加密** 的 CalDAV 协议
- 智能识别时的 Deepseek API 调用走 HTTPS 加密传输
- 无第三方追踪、无广告、无数据分析服务

### 权限说明

| 权限 | 用途 |
|------|------|
| `storage` | 本地保存配置信息 |
| `notifications` | 显示 Chrome 原生通知 |
| `alarms` | 定时触发日历同步 |
| `offscreen` | 播放警报音（无需可见标签页） |
| `system.display` | 检测显示器状态（为弹窗定位） |
| `sidePanel` | 在侧边栏显示 UI |
| `contextMenus` | 提供右键菜单快速创建 |
| `*.icloud.com/*` | 与 iCloud CalDAV 通信 |
