📌 核心功能

Chrome 侧边栏里，你的 iCloud 日历全天候在线

📅

今日日程一览

侧边栏直接查看 iCloud 日历行程，每分钟自动同步，已过期日程自动变灰。

🔔

强力弹窗提醒

日程前 30/15/5/0 分钟弹出精美提醒窗口，带铃铛动画和倒计时。

🔊

响铃告警

日程临近时自动播放警报音，浏览器后台也不错过会议。

🧠

智能创建日程

粘贴一句话自动解析："明天下午3点在星巴克开会" → AI 生成日程。

🖱️

右键快速创建

选中网页文字 → 右键 → "添加日程到 WeCal" → 一步创建。

☁️

iCloud 直连

CalDAV 协议直接读写你的日历，支持中国区（.cn）和国际区（.com）。

🔒

隐私优先

所有数据存本地，不上传任何个人信息，与 iCloud 通信全程 HTTPS。

📊

月视图浏览

整月日程一目了然，轻松规划未来行程。

⚡

轻量省资源

仅 106KB 大小，Manifest V3 架构，内存占用极低，不影响浏览体验。
